# Integration 2 – Key Whisperers

## Overview
**Key Whisperers** is an interactive website that transforms everyday keys into storytellers. In a world of disposable objects, keys often end up forgotten in drawers, pockets, or hooks. This project explores their hidden significance and proposes three creative alternative uses that spark reflection, play, and imagination:

1. **Windchimes for memories** – Keys become delicate instruments of reflection.  
2. **Garden gossip sensors** – Keys track playful, whimsical interactions outdoors.  
3. **Ritual planting for new luck** – Keys inspire symbolic gestures and rituals.  

Through storytelling, visual metaphors, and micro-interactions, the site encourages visitors to see ordinary keys as **personal artifacts** carrying the imprint of life’s moments.


**Live demo:** [View Key Whisperers](https://ulrikagarisone.be/integration2/)

## Briefing Requirements & Implementation
This project followed the Integration 2 briefing, which asked for:

| Requirement | How It Was Implemented |
|-------------|------------------------|
| Choose a common household item | Keys, universally owned and often overlooked. |
| Three alternative uses | Windchimes, garden gossip sensors, ritual planting. |
| Coherent overarching concept | “Key Whisperers” – keys as storytellers carrying emotional weight. |
| Storytelling techniques | Narrative copy, playful visuals, interactive micro-interactions. |
| Interactive website | Drag-and-drop, hover-to-reveal, and planting mechanics using DOM manipulation and CSS animation. |
| Form / Challenge | Sign-up form with at least 3 input types; works with or without JS. |
| Reviews / Testimonials | Loaded dynamically from a database. |
| Documented UX & VD process | Lo-fi/hi-fi wireframes, user flows, moodboards, inspirations documented in Figma. |
| Unique visual style | Warm, whimsical design combining illustrations, photos, and typography. |

---

## Approach / Concept
- **Theme:** Keys as silent witnesses of daily life, carrying memories and emotional weight.  
- **Twist:** Transform ordinary keys into interactive objects that reveal stories and inspire playful actions.  
- **User Flow:** Explore keys → interact with one of the three alternative uses → participate in a challenge → view testimonials and feedback.  
- **Design:** Warm, nostalgic color palette; playful typography and illustrative visual language.  
- **Technical Highlights:** Drag-and-drop interactions, hover animations, progressive storytelling, interactive form with multi-input types, dynamic database-loaded testimonials.


---

## Features
- **Windchimes Interaction:** Drag keys to build a musical memory chime.  
- **Garden Gossip:** Hover or place keys in a virtual garden to trigger playful feedback.  
- **Ritual Planting:** Plant keys to trigger symbolic animations and encourage reflection.  
- **Sign-Up Form:** Collect user input with progressive enhancement and validation.  
- **Reviews / Testimonials:** Loaded from a database and dynamically displayed.  

---

## Process
1. **Ideation & Concept**  
   - Observed keys in daily life and explored hidden emotional significance.  
   - Developed a narrative framework positioning keys as storytellers.

2. **Research & Storytelling**  
   - Studied storytelling websites, brand microcopy, and editorial layouts.  
   - Collected visual and conceptual references in Figma for inspiration.

3. **Brainstorm & Alternative Uses**  
   - Mind-mapped multiple interactive ideas.  
   - Selected three concepts that fit a cohesive story.  

4. **Wireframes & Interaction Design**  
   - Sketched lo-fi wireframes for drag-and-drop, hover-reveal, and planting interactions.  
   - Built hi-fi Figma wireframes with detailed user flows, error handling, and heuristics.  

5. **Visual Style & Final Design**  
   - Created moodboards combining keys, nature, and memories.  
   - Developed a whimsical, warm visual language for the website.
