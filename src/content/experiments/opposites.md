# Opposites — Chaos / Order / Dark / Light (p5.js)

## Project Overview
This project explores four abstract concepts — **Chaos, Order, Dark, and Light** — through creative coding in p5.js.  
Each scene is generated in real-time and reacts visually over time through motion, noise, and transformations.

 The goal was not to illustrate literal scenes, but to interpret feeling, energy, balance, and tension between opposites — using only shapes, motion, and rhythm.

 Live preview: https://ulrikagarisone.be/opposites/  
*(Press keys to switch scenes — see instructions below)*

Press these keys to explore each animated concept:

| Concept | Key |
|--------|-----|

| Dark | **B** |
| Light | **N** |

*(No mouse interaction — the sketch is controlled fully through keyboard input.)*

---

## Concept & Approach
Instead of representing literal objects, each scene expresses mood and structure through:

- Motion dynamics (fast vs. slow, jitter vs. smooth)
- Symmetry vs. randomness
- Density and spacing
- Light + shadow simulation through shapes and gradients
- Noise & sine wave movement
- Object systems, loops, and arrays

### Idea Philosophy
I approached this assignment as **four internal worlds**:

| Scene | Interpretation |
|-------|----------------|
| **Chaos** | Energy exploding in unpredictable patterns; noisy motion, breaking symmetry |
| **Order** | Structured geometry, orbital motion, grid rhythm, predictable flow |
| **Dark** | Heavy atmosphere, low visibility, emerging edges, slow mysterious movement |
| **Light** | Ethereal particles, glow-like waves, airy motion, openness & expansion |

---

## Code Principles Used
- variables & arrays
- objects for generative elements
- `noise()` & `sin()` / `cos()`
- transformations (`push`, `pop`, `translate`, `rotate`)
- custom drawing functions per scene
- loops & grids
- conditional logic for scene switching

---

## Learning Outcome
This project deepened my understanding of:

- Emotion through motion & form
- Balancing randomness with design control
- Modular creative coding workflow
- Using system thinking to express abstract moods visually
- Avoiding literal representation and thinking in **visual feeling**

This exercise expanded the way I think about UI motion, product atmosphere, and how simple shapes can carry meaning when paired with behavior.
