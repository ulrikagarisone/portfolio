# Unclear Coffee Machine Interface at Campus

## Context
**Location:** Devine Campus, between classes  
**Situation:** A student tries to get coffee but fails because the cup is not placed properly—the machine gives no useful feedback.

## The UX Problem
The coffee machine does not provide guidance when something goes wrong. If the cup is not positioned exactly right, it simply doesn't work, and there's no clear message about what needs fixing.

**Observed behavior:**
- Student places cup → machine doesn't start
- Student adjusts cup → still nothing
- Student looks confused → tries again
- Eventually gives up or asks for help

## Why It Matters
Creates unnecessary confusion and frustration, especially under time pressure. Users may blame themselves instead of the product. 

**Impact:**
- Wasted time between classes
- Negative campus experience
- Missed caffeine = grumpy students
- Everyday inefficiency adds up

## Root Causes
1. **Missing visual or audio feedback** for errors
2. **Unclear cup placement requirements** — no guides or markings
3. **No real-time instructions** for new users
4. **Silent failures** — machine just doesn't work, no explanation

## Solution Directions

### Quick Fix
- Add LED lights around cup area:
  - Red = Wrong position
  - Green = Ready to brew
- Simple audio cue: "Please adjust cup"

### Medium Term
- Display screen shows cup placement animation
- Visual guide printed on machine surface
- Step-by-step instructions with illustrations

### Long Term
- Smart sensors detect cup automatically
- Machine guides user: "Move cup 2cm left"
- Success sound when correctly placed
- Universal design research for all cup types

## UX Principles Applied
- **Error prevention** — Guide users before problems occur
- **Feedback** — Always show system status
- **Usability** — Don't make users think
- **Recognition over recall** — Show, don't tell

## Related Patterns
- Microcopy for guidance
- Progressive disclosure
- Visual affordances
- Error recovery systems

---

**Key Takeaway:** Silent failures frustrate users. Good feedback turns confusion into confidence.
